Política de Privacidade – KNOX Postador

Última atualização: 23/11/2026

O KNOX Postador é uma ferramenta pessoal, usada apenas pelo dono do canal KNØX (@Kn0xMe), para enviar e programar vídeos do próprio canal. Ela não é oferecida a outras pessoas.

Dados usados

A ferramenta usa os Serviços de API do YouTube apenas para enviar vídeos, definir título, descrição, playlist e data de publicação no canal do próprio dono. Não coleta, vende nem compartilha dados de terceiros.

As credenciais de acesso ficam guardadas somente no computador do dono do canal.

Como os dados são guardados e apagados

A ferramenta não tem servidor nem banco de dados: nada é enviado a outro lugar além do próprio YouTube. A única coisa guardada é o token de acesso do Google, num arquivo no computador do dono do canal.

Para apagar esses dados: revogue o acesso do KNOX Postador em myaccount.google.com/permissions (o token deixa de funcionar na hora) e apague o arquivo do token (youtube_token.json) da pasta de credenciais no computador. Os dados obtidos pela API do YouTube não são guardados por mais de 30 dias; os vídeos enviados ficam no canal do YouTube e podem ser apagados a qualquer momento no YouTube Studio.

Termos e privacidade do YouTube e do Google

Ao usar esta ferramenta, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

English summary

KNOX Postador is a personal tool used only by the owner of the KNØX channel. It uses YouTube API Services solely to upload and schedule the owner's own videos. No third-party data is collected, sold or shared; credentials are stored only on the owner's computer. Use is subject to the YouTube Terms of Service and the Google Privacy Policy.

Data storage and deletion: the tool has no server or database. The only stored item is the Google OAuth token, kept in a local file on the owner's computer. To delete it, revoke access at myaccount.google.com/permissions and delete the local token file. Data obtained from the YouTube API is not stored for more than 30 days; uploaded videos remain on the owner's YouTube channel and can be deleted at any time in YouTube Studio.
